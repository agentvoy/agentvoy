# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.3.x   | Yes       |
| < 0.3   | No        |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Email **cthecm@gmail.com** with:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

We will respond within 48 hours and aim to release a fix within 7 days for critical issues.

## Scope

- `agentvoy` CLI (npm)
- `@agentvoy/core` (npm)
- `agentvoy-guard` (PyPI)

## Out of Scope

- Vulnerabilities in dependencies (report to their maintainers)
- Issues in user-generated `agent.guard.yml` configs
